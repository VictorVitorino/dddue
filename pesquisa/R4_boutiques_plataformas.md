## 1. Resumo executivo

1. **O mercado de Tech DD se "plataformizou" em três camadas:** (i) plataformas de análise de código/arquitetura usadas por consultorias como motor da diligência (SIG Sigrid, CAST Highlight, CodeScene, Sema), (ii) scanners de composição/segurança (Black Duck, Snyk, Revenera Code Insight) e ratings externos de cyber (BitSight, SecurityScorecard), e (iii) data rooms e copilotos de IA que leem o data room inteiro (Datasite, Intralinks, Ansarada, Harvey, Hebbia, Luminance, Kira) — com uma quarta camada emergente de **agentes open-source** que já replicam o fluxo completo.
2. **Evidência mais forte da sessão — SIG/Sigrid é vendido como motor de Tech DD para consultorias:** a documentação oficial afirma que Sigrid permite a "users, usually consultancy partners, to deliver high-quality Tech Due Diligence assessments", com fluxo de 3 passos (Sigrid Local rodado por funcionário do target → interpretação → relatório), benchmark de "25,000 industry systems", dataset de "over 400 billion lines of code", escala de 1–5 estrelas (5%/30%/30%/30%/5%), Open Source Health em 6 riscos e detecção de código gerado por IA com acurácia declarada de "95% - 99%".
3. **Code-level evidence virou padrão de mercado.** CAST Highlight se descreve como "automated source code analysis of hundreds of applications" cobrindo "Cloud Maturity, Open Source risks, Resiliency, Agility"; o R2 registrou a Deloitte concluindo uma Tech DD de 300K LOC "in less than 10 days" com CAST Highlight, entregando scripts para o próprio target rodar o scan (mesmo modelo "scan dentro do ambiente do target" do Sigrid Local).
4. **Licenciamento e open source são linha própria de diligência.** Black Duck Detect "scans code bases ... to perform compositional analysis" identificando "open source components, licenses, and security vulnerabilities"; Snyk cobre Open Source, Code, Container e IaC; Revenera (Flexera) publica relatórios SBOM SPDX/CycloneDX do Code Insight. Isso ancora o claim do deck A&M sobre multas de software não licenciado em ferramenta, não só em questionário.
5. **IA agêntica sobre o data room já é commodity técnica.** No GitHub há 34 repositórios que automatizam DD sobre data rooms com LLMs; o mais popular (117 estrelas) usa "13 AI agents" em "9 domains" e "trace every one to an exact page and quote", com saídas HTML interativo + Excel de 16 abas + JSON; outro declara "48 hours" vs "3–4 weeks" e "$45,000 / deal" vs "$75,000–$150,000". Os claims de preço/velocidade são auto-declarados (não auditados), mas mostram a âncora de expectativa que o comprador passará a usar.
6. **Rastreabilidade e "human gate" são o diferencial que sobrevive à IA.** Os projetos open-source e o PwC/Harvey (R2: workflow de red flags executado ">10,000 times") convergem em: citação por página, score de materialidade/confiança, aprovação humana antes do memo de IC ("credibility gate"), export .docx/.pptx. Sigrid gera relatórios automáticos em PowerPoint ("All generated reports are PowerPoint documents").
7. **Cyber DD "outside-in" é produto separado.** BitSight expõe via API "ratings, assets, findings" atuais e históricos (evidência via ferramenta de automação NVISO); SecurityScorecard e BitSight vendem módulo M&A (hypothesis). Isso permite um pré-screening de cyber sem acesso ao target — complementar ao "light pentest" do deck A&M.
8. **AI Due Diligence e "AI code governance" são a nova linha.** Sigrid já tem módulo de AI Governance (detecção de código gerado por LLM, "19 out of 20 code snippets are correctly classified") e "AI Transformation View" (mapeia domínios funcionais e "estimated person-months"); CodeScene posiciona o MCP server para "Safeguard AI-Generated Code"; R2 registrou KPMG apontando "the AI blind spot" (só 33% investigam dívida técnica/IA pré-deal).
9. **Brasil: oferta pública de Tech DD é rasa e não verificável nesta sessão.** Não foi possível abrir nenhum site de firma brasileira (403). O R2 confirmou apenas Deloitte BR com páginas "IT M&A"/"Due Diligence de TI" e ferramentas "Digital Deal Room" e "Synapse". Para Integration, Falconi, Peers, Visagio, BIP, Protiviti/ICTS, Grant Thornton, BDO, RSM, Forvis Mazars, Baker Tilly, Crowe, ACE Cortex, Elogroup, Vallya, Stefanini, TIVIT, Compass UOL, Nava, DBServer: **nome exato de serviço de Tech DD = não encontrado**; registrei apenas hipóteses de posicionamento. Não há repositório em português sobre "due diligence de TI" no GitHub (0 resultados).
10. **Implicação para A&M:** o mercado pede (a) evidência de código e não só entrevistas, (b) OSS/licenças e cyber externo como módulos com ferramenta, (c) leitura do data room por IA com citação e revisão humana, (d) AI DD/AI debt, (e) prazo e preço explícitos (48h–10 dias para red flags; 2–4 semanas full), (f) relatório gerado automaticamente. A&M pode montar isso com parcerias (SIG/CAST/CodeScene + Black Duck/Snyk + BitSight/SSC) e um orquestrador próprio de agentes sobre VDR, reaproveitando o modelo de 6 competências × níveis 1–3 como "esquema de scoring" do sistema.

## 4. Ferramentas/plataformas — o que cada camada automatiza (síntese)

1. **Análise de código e arquitetura (Sigrid, CAST Highlight, CodeScene, Sema):** volume em pessoa-mês, manutenibilidade vs. benchmark, acoplamento/entanglement de componentes, hotspots, ownership/risco de pessoas-chave, dívida técnica, prontidão para cloud, código gerado por IA. Modelo operacional comum: **scan dentro do ambiente do target** (Sigrid Local; scripts Deloitte/CAST) — resolve a objeção de confidencialidade do código.
2. **Composição e licenças (Black Duck, Snyk, Revenera Code Insight, Sigrid OSH):** inventário de componentes OSS, CVEs (CVSS), licenças copyleft, SBOM SPDX/CycloneDX, "freshness"/"activity" de dependências. Base objetiva para o risco "software não licenciado" e para CAPEX de remediação.
3. **Cyber outside-in (BitSight, SecurityScorecard):** rating e histórico sem acesso ao target; útil em pré-LOI/VC e para monitoramento pós-deal do portfólio.
4. **Data room + IA (Datasite, Intralinks, Ansarada, Drooms, Imprima; Harvey, Hebbia, Luminance, Kira; agentes open-source):** indexação, redação, Q&A, sumarização, extração de cláusulas (change of control, anti-assignment), red flags, cross-referência entre domínios, memo de IC com citação. Métricas de mercado publicadas (R2): Harvey/PwC >10.000 execuções; PwC separação de apps "4x faster, >90% accuracy"; PwC/Palantir "up to 50% faster", "-45% one-time costs".
5. **Gestão do ciclo (DealRoom, Midaxo, Devensoft):** pipeline, request lists, tracker de DD, PMI/100 dias — hypothesis (não verificado).

## 6. Implicações para a A&M — o que o mercado pede (evidência → implicação)

1. **Evidência de código, não só entrevistas.** Sigrid/CAST/CodeScene são o padrão dos concorrentes (Deloitte: 300K LOC em <10 dias). → A&M deve adicionar módulo "Code & Architecture Scan" (nível 3 das competências Sistemas/Digital) com parceiro de plataforma e protocolo "scan no ambiente do target".
2. **OSS/licenças e cyber externo como módulos com ferramenta.** Black Duck/Snyk/Revenera + BitSight/SSC. → Transformar "Light Pentest" e "software não licenciado" em entregáveis tool-based (SBOM + rating) com preço fechado.
3. **Leitura do data room por IA com citação e gate humano.** PwC/Harvey (>10k execuções), agentes open-source (13 agentes, citação por página, memo IC). → "Red Flag em 48–72h" como produto de entrada (VC/PE), alimentando o DD completo; a A&M pode construir o orquestrador em cima de LLM e do seu esquema de 6 competências × níveis 1–3 como taxonomia de findings.
4. **AI DD / AI code governance.** Sigrid detecta código IA (95–99%) e mapeia domínios; KPMG "AI blind spot" (R2). → Criar "AI & Data Due Diligence" (maturidade, AI debt, governança, licenças de modelos/dados, LGPD).
5. **Prazo, preço e relatório automatizado.** Open-source anuncia "48h / US$ 45k" vs "3–4 semanas / US$ 75–150k"; Sigrid gera PPT automaticamente. → Publicar SKUs por tempo (48h / 2 semanas / 6 semanas) e automatizar o relatório A&M (findings → matriz de risco → CAPEX/OPEX) a partir de JSON padronizado.
6. **Pós-deal como extensão do mesmo dado.** CodeScene/Sigrid acompanham "delta quality" e objetivos; BitSight monitora rating. → "Value Monitoring" para fundos (portfólio) reaproveitando a base de DD — alinhado ao VMaaS.
